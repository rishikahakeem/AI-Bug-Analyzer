
# AI Software Bug Analyzer & Code Fixer

## Project Overview

AI Software Bug Analyzer & Code Fixer is a web-based application that analyzes source code, detects bugs, explains the cause of errors, suggests fixes, generates corrected code, and provides a structured analysis report.

## Features

- User Signup and Login
- Forgot Password
- Reset Password
- Code Editor
- File Upload
- GitHub Code Import
- AI Code Analysis
- Static Code Analysis
- Bug Detection
- Bug Severity Detection
- Automatic Bug Fixing
- Root Cause Explanation
- Suggested Fix
- Corrected Code Generation
- Security Analysis
- Complexity Analysis
- Code Quality Score
- Test Case Generation
- Post-Fix Analysis
- Analysis History
- User Dashboard
- Admin Dashboard
- Admin Access Control
- PDF Report Download
- TXT Report Download
